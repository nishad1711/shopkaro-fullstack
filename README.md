## 👨‍💻 About This Project

ShopKaro is one of my first full-stack projects, built while learning Java and Spring Boot from **Telusko** on YouTube. It is a simple e-commerce web application where you can browse products, search by keyword, add items to cart, and place orders.

This project helped me understand how a real backend and frontend connect together and how to deploy a full-stack app to the cloud.

---

## ✨ Features

- Browse and search products by name, brand, category
- Add, edit, delete products with image upload
- Shopping cart with quantity controls and price summary
- Order placement with success animation
- Fully responsive UI inspired by Myntra and Flipkart

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, React Router, Axios |
| Backend | Spring Boot, Spring Data JPA |
| Database | H2 In-Memory |
| Deployment | Vercel (frontend) + Railway (backend) |

## 🚀 Run Locally

**Backend:**
```bash
cd project1-spring
mvn spring-boot:run
```

**Frontend:**
```bash
cd shopkaro
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)
